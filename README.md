# FINE3300-2026-A1

FINE 3300 (Python for Finance Professionals), Assignment #1: a CAD ⇄ USD exchange rate calculator built with Python, Visual Studio Code, Git and GitHub.

## Overview

The program reads the annual exchange rates published by the Bank of Canada and converts an amount from Canadian dollars to US dollars, or from US dollars to Canadian dollars. It uses the **latest USD/CAD rate**, which is the last row of the data file.

The assignment has two parts:

1. **Part 1: Exchange Rates.** An `ExchangeRates` class that reads the rate file and converts between CAD and USD (`ExchangeRates.py`).
2. **Part 2: Vibe Coding.** An AI model (LLM) wrote the same program from a plain-English prompt (`ExchangeRatesAI.py`). I then compared the two versions.

## Data

`BankOfCanadaExchangeRate.2026.csv` has one row per year and one column per currency pair. Each value is the number of Canadian dollars per one unit of the foreign currency. This project only uses the `FXAUSDCAD` column (USD/CAD).

The last row (`2025-01-01`, the 2025 annual average) gives the latest rate:

> **1 USD = 1.3978 CAD**

## How It Works

### The `ExchangeRates` class

- **`__init__(file_name)`** stores the file name and reads the file when the object is created.
- **`__read_file()`** is a private method. It reads the CSV, finds the `FXAUSDCAD` column in the header row, and saves the date and the rate from the **last row**.
- **`convert(amount, from_currency, to_currency)`** converts the amount:
  - USD → CAD: `amount × rate`
  - CAD → USD: `amount ÷ rate`
  - Same currency: the amount is returned unchanged
- **`get_rate()`** and **`get_date()`** are public methods that return the rate and its date.

In line with Lecture #4, the data members are private (double underscore), and the main program only uses the class through its public methods.

### User input

The program uses `input()` to ask for the amount, the "from" currency and the "to" currency. As the assignment allows, it assumes the user enters valid values, so it does not validate them. The result is rounded to the nearest penny and printed with a dollar sign and the currency code.

## How to Run

1. Clone the repository. In Visual Studio Code, choose **File → Open Folder** and open the `FINE3300-2026-A1` folder itself, so the program can find `BankOfCanadaExchangeRate.2026.csv`.
2. Open a terminal in VS Code (**Terminal → New Terminal**). Make sure it is in the `FINE3300-2026-A1` folder, then run:

```bash
python3 ExchangeRates.py
```

(On Windows, use `python ExchangeRates.py`.)

3. Enter the amount, the currency to convert from, and the currency to convert to.

### Comparison of my code and the AI's code

For Part 2, I gave the single prompt above to Claude Opus 5.5 (Anthropic). Its first answer ran correctly, so I did not need any follow-up prompts. Both programs give identical results ($100,000 USD = $139,780.00 CAD and $100,000 CAD = $71,540.99 USD), and both have the same overall design: an `ExchangeRates` class reads the CSV with Python's `csv` module and takes the `FXAUSDCAD` rate from the last row, and a `convert` method multiplies by the rate for USD to CAD and divides by it for CAD to USD. The AI's version is about half as long (32 lines versus 64) and more compact. It uses `csv.DictReader` to look up the column by name, reads the file directly in `__init__`, uses f-strings and docstrings, and adds `.strip()` to remove extra spaces from the user's input. My version follows the object-oriented principles from Lecture #4 more closely. The rate, date and file name are private members (double underscore), the file is read in a private helper method, and the main program gets the values through the public `get_rate()` and `get_date()` methods. In the AI's version the rate is a public attribute, so any code can overwrite it: setting `rates.usd_to_cad = 2.0` changes every later conversion. My `convert` method also converts the currency codes to upper case itself, while the AI's relies on the main program to do this. As a result, calling `rates.convert(100, "usd", "cad")` directly on the AI's class returns 71.54 instead of 139.78. Finally, my output gives more information: it shows the Bank of Canada rate and date used, as well as both the original and the converted amounts, while the AI's prints only the converted amount. Overall, the AI quickly produced correct, clean code from a high-level description, but I still had to test and review it to find the differences in encapsulation and input handling.
